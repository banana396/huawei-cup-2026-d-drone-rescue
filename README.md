## 重现验收

在仓库根目录使用 Python 3.11+ 安装 `requirements-audit.txt` 中的依赖，然后顺序执行：

```powershell
python .\D题独立验收\independent_audit.py
python .\D题独立验收\supplemental_checks.py
python .\D题独立验收\write_report.py
```

主检查器返回码 0 代表计算过程没有发现物理断链或运输资源问题；**最终是否通过应读取** `证据/最终验收结论.json` 的 `strict_workbook_verdict`。官方提交模板没有 Q3 运输明细，必须和 `D题优化/结果/q3_solution.json` 一起验收。若需重新运行优化搜索，请参照 `D题优化/README.md`；该过程会重写优化目录里的中间结果。

数据、距离、能耗和通信判断依赖报告第 6 节声明的模型口径；仓库不主张方案全局最优。`D题求解` 中旧论文、旧压缩交付包和大量生成依赖未纳入本发布版本。
